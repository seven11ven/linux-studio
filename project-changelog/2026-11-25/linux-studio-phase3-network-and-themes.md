## Changes

### Phase 3: network
- **`src/network/netpolicy.py`:** shared rules: exact host-name check (refuses IPs, including hex/short forms), public-address check
  (including IPv4 wrapped in IPv6), and the `network.json` store (lock, atomic replace, 0600, damaged file = network off).
- **`src/network/studio_proxy.py`** (host, stdlib only):
  - only CONNECT to port 443, exact-host allowlist, DNS done on the host
  - non-public addresses refused; blind tunnel with no traffic log
  - pop-up handling: one at a time, max 3 waiting, closed or timed out = denied for the session, block-all option
  - time limits, and open tunnels close when a site is blocked or the network is turned off
- **`src/network/net_bridge.py`** (inside the sandbox): `127.0.0.1:3128` → proxy socket.
- **`src/network/approval_prompt.py`** and **`sites_manager.py`:** GTK4 windows matching mockup screens 2 and 3.
  The pop-up has a 1-second button delay, no default button, no wrapping of site names, and a "Block all new sites" button.
- **`src/launcher/linux-studio`:**
  - starts and stops the proxy, mounts the socket and bridge read-only, sets the proxy variables, and uses an empty `resolv.conf`
  - new options `--network` and `--allow-x11`
  - the settings merge moved inside the sandbox (`src/launcher/apply_settings.py`), and `jq` is no longer needed on the host
- **Tests:** `tests/test_proxy.py` (17 unit tests), `tests/network-test.sh` (21 checks). `tests/isolation-test.sh` updated to "no direct internet".
- **Version control:**
  - Phase 2 launcher and isolation test → `version-control/launcher/2026-11-25_1439/`
  - workflow → `version-control/build-workflow/2026-11-25_1451/`

### Security review findings (jake-lockley) and what was done
| # | Severity | Finding | Result |
|---|---|---|---|
| 1 | High | Host-side settings merge followed links planted by the sandbox → could read or overwrite real files (in pushed Phase 2 code) | **Fixed.** Merge moved inside the sandbox. Verified with a planted link: the host file was untouched. |
| 2 | Medium | Hex or short IP forms (`0x8.0x8.0x8.0x8`, `1.0x1`) passed the "names only" check | **Fixed** (`inet_aton` and numeric-host probe). Unit-tested. |
| 3 | Medium | Pop-up flooding | **Fixed:** one at a time, max 3 waiting, closed = session deny, plus a "Block all new sites" button (PM choice). |
| 4 | Medium | Pop-up mis-read or mis-click | **Fixed:** no wrapping of the site name, 1-second button delay. |
| 5 | Medium | X11 gives the sandbox keystroke injection into the desktop | **Fixed:** refused unless `--allow-x11` (PM choice). |
| 6 | Low | NAT64 addresses (`64:ff9b::/96`) counted as public | **Fixed** (also 6to4 and Teredo). Unit-tested. |
| 7 | Low | Unicode digit in the port caused error output | **Fixed** (ASCII-only port, silent error handler). |
| 8 | Low | Slow clients and lookups could hold connection slots | **Fixed** (overall request deadline, send timeout, 10 s lookup limit). |
| 9 | Low | Tunnels survived a block or network off | **Fixed** (re-check every 5 s). |
| 10 | Low | An approved name pointing at your own public IP | **Accepted** as low risk; documented. |

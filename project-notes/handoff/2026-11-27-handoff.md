## 1. Where the project stands (summary)

**Linux Studio** is a privacy-focused, sandboxed code editor (Code - OSS 1.148.0) for Ubuntu 24.04+ and Linux Mint, shipped as a `.deb`.
- **Sandbox:** the editor and its extensions see only one project folder, inside a bubblewrap sandbox.
- **Network:** only through an approval proxy (exact sites, HTTPS only), with a fake identity.
- **X11:** a private display (Xephyr).
- **Runtime:** a private Debian runtime with language tools.

## 3. What's left (in order)

### 3.1 Firefox private browser (blocks dev8) — ask the PM these 4 questions first
The PM deferred these on 2026-11-27 ("ask me these another time"):
1. **Engine:** Firefox ESR from Debian (recommended: official security archive, signature-checked, version 153.8, about 300 MB installed / +80–90 MB in
   the package) **or** LibreWolf (its own repo `repo.librewolf.net`; key verification undocumented).
2. **Where web links open by default:** a Settings choice defaulting to the private browser, a Settings choice defaulting to the Linux Studio tab, or
   always the private browser.
3. **Memory:** remember logins and history (in Linux Studio's private data), forget on close (recommended), or a Settings choice.
4. **uBlock Origin** from Debian (`webext-ublock-origin-firefox` 1.67), recommended yes.

**Proposed design (research done):**
- **Same sandbox:** it runs inside the editor's sandbox, so it uses the proxy and inbox and the fake identity, and localhost sign-ins work.
- **X11:** it gets its own private display window ("Linux Studio · Private browser").
- **Hardening** through Firefox's `policies.json`:
  - DisableTelemetry, DisableFirefoxStudies, DisablePocket, DisableFeedbackCommands, DisableFirefoxAccounts, DisableAppUpdate
  - DontCheckDefaultBrowser, OverrideFirstRunPage, PasswordManagerEnabled/OfferToSaveLogins
  - EnableTrackingProtection, locked Preferences
  - Handlers for `linux-studio://`, sent to `/run/linux-studio/bin/xdg-open`
- **Then:**
  1. a mockup (the Settings choice, plus how the browser opens) → PM approval
  2. add the packages to `scripts/build-runtime.sh` and rebuild the runtime (back up first)
  3. launcher changes, plus the link router / `xdg-open` routing to Firefox
